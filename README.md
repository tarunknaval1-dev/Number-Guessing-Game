# Number-Guessing-Game

A beginner-friendly Python Number Guessing Game with difficulty levels, limited attempts, scoring system, hints, and replay functionality.

## 📌 About the Project

The Number Guessing Game is a console-based Python project where the computer generates a random number and the player has to guess it within a limited number of attempts.

The game provides three difficulty levels:

- 🟢 Easy
- 🟡 Medium
- 🔴 Hard

The player receives hints after every incorrect guess and earns points based on the difficulty and number of attempts used.

## ✨ Features

- 🎮 Three difficulty levels
- 🔢 Random number generation
- ⏳ Limited attempts
- 📈 Higher score for higher difficulty
- 💡 "Too High" and "Too Low" hints
- 🏆 Score system
- 🔄 Replay option
- 📊 Total score tracking
- 🎯 Number validation
- ❌ Invalid input handling

## 🎚️ Difficulty Levels

| Difficulty | Number Range | Attempts | Base Score |
|------------|--------------|----------|------------|
| Easy | 1 - 50 | 10 | 100 |
| Medium | 1 - 100 | 7 | 200 |
| Hard | 1 - 200 | 5 | 300 |

## 🏆 Scoring System

The game rewards players for guessing the number using fewer attempts.

- Easy → 100 base points
- Medium → 200 base points
- Hard → 300 base points
- Fewer attempts → Higher score
- Fast guessing → Bonus points
- Minimum score → 10 points
